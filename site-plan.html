Tanner Tinsley Personal Site Plan

Purpose

The purpose of this website is to showcase my projects, skills, and experience as a software developer. It will act as a portfolio to help me get internships and jobs.

Audience

My target audience includes employers, recruiters, and other developers who want to see my coding skills and projects.

Dynamic Elements (JavaScript)

JavaScript will be used to dynamically display projects, filter content, and update information without reloading the page. For example, users will be able to filter projects by category and interact with elements like buttons and forms.
