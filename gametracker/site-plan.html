Game Tracker Site Plan

Purpose

This website allows users to view and filter a list of my favorite video games. Visitors can browse games and filter them by genre using interactive controls.

Audience

This site is for gamers and friends who want to see recommended games and explore different genres.

Dynamic Elements

JavaScript will dynamically display games, filter them, and respond to user interaction using event listeners and DOM updates.
