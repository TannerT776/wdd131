Project Site Plan

Tanner T.

Purpose

The purpose of this site is to showcase a gamified portfolio featuring 8-bit interactive elements. It serves as a hub for my web development projects and a professional landing page for potential employers.

Target Audience

My target audience includes tech recruiters, fellow developers, and DIY enthusiasts. They value clean code, creative UI, and interactive user experiences.

Color Palette

Primary: #EE7125 (Orange) | Secondary: #1a1a1a (Dark Grey) | Accent: #00ff00 (Heist Green)

Typography

Heading Font: 'Courier New', monospace | Body Font: 'Arial', sans-serif

Dynamic Elements

  • Interactive Sprite: Using DOM event listeners to move the Dallas character.
  • Project Filter: An array of project objects filtered by category using the .filter() method.
  • Conditional UI: Modals that trigger based on player proximity to office objects.

Wireframe

The site will feature a top navigation bar, a central interactive "office" game area, and a dynamic project gallery below it.
